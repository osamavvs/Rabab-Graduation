# 🛡️ أداة اختبار التحمل الدفاعية (DDoS Test Tool)

## 📌 الغرض التعليمي
أداة تستخدم في بيئات معملية مغلقة لاختبار قدرة الخوادم على مقاومة الهجمات الرقمية.

## ⚙️ المتطلبات
- Python 3.9+
- حساب GitHub
- بوت تليجرام (من @BotFather)

## 🚀 طريقة النشر
1. Fork المستودع
2. إنشاء بوت تليجرام واحصل على التوكن
3. النشر على Render أو Railway
4. أضف التوكن في متغيرات البيئة

## 🛑 تحذير
استخدام هذه الأداة ضد مواقع لا تملكها هو عمل غير قانوني.
